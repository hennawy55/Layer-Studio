# Layer Studio

Offline-first, non-destructive image composition editor for Android and Windows, built with Flutter.

## Features
- Add, transform, reorder, hide, lock and delete text/image layers.
- Arabic and English UI with RTL/LTR support.
- Light and dark themes.
- Local projects with autosave and portable `.layerstudio` archives.
- Export PNG, JPEG and WebP at source dimensions.
- No accounts, backend, analytics or network dependency at runtime.
